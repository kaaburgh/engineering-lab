# Engineering research repository

For the owner's engineering research, use this public repository as the
canonical home for research, hypotheses, evidence, and supporting material.
Use `benchmarks/quake-staging/` for the DOSBox/Quake work. The private
`kaaburgh/configs` repository is historical provenance, not the destination
for new engineering research; preserve historical source references where useful.

This repository is public. Never add game assets, proprietary executable or
firmware contents, raw guest/native snapshots, process maps, raw sampled
addresses, private logs, secrets, or local machine configuration. Publish only
appropriately reviewed derived observations, source code, hashes, and tests.
Separate exploratory performance estimates from established results. Preserve
reproducibility, source revisions, validation boundaries, and limitations.
